# Blog Images

Keep only this blog's images in this folder.

Recommended naming:

- `featured-image.webp`
- `section-01.webp`
- `section-02.webp`

Use descriptive lowercase filenames with hyphens. Prefer WebP for web performance when possible.

Example in the blog file:

```html
<img src="images/section-01.webp" alt="Useful descriptive alt text">
```
