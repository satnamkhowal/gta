# Groot Academy AI Work Logs

This folder records work performed by AI-assisted tools on the repository so future agents can check existing work before making changes.

## Required workflow

1. Read this folder before starting repository work.
2. Check the current repository tree and recent commits for overlapping work.
3. If the requested task already exists, review it first and only make changes that improve correctness, SEO, accessibility, performance, or maintainability.
4. If the task is complete and does not need improvement, move to the next pending task instead of duplicating work.
5. Record the files changed, reason for the change, status, and any follow-up items in a dated log file.
6. For Groot Academy Google Business Profile content, create or update a matching SEO-focused blog under `/blogs/<seo-slug>/` and provide the canonical public URL in the related work log.

## Status terms

- `AUDITED` — existing work reviewed.
- `CREATED` — new work added.
- `UPDATED` — existing work improved.
- `SKIPPED` — already complete; no useful change needed.
- `PENDING` — follow-up work still required.
